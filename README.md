# AI Chatbot

A simple AI-powered chatbot built with Python that interacts with users through a command-line interface. The chatbot responds to basic user queries and demonstrates fundamental concepts of conversational AI and Python programming.

## Features

* Interactive command-line chat
* Responds to common user questions
* Easy to customize with new responses
* Beginner-friendly Python project

## Technologies Used

* Python 3

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python chatbot.py
```

## Example

```text
You: Hello
Bot: Hi! How can I help you?

You: How are you
Bot: I'm doing great! Thanks for asking.
```
